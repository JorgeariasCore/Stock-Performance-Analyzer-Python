# Stock-Performance-Analyzer-Python
What this project shows in an interview This project shows that you understand:  
- how to pull market data
- how to clean time-series data
- how to calculate returns
- how to measure volatility
- how to use rolling windows for moving averages
- how to summarize stock behavior clearly

 “I built a Stock Performance Analyzer in Python using yfinance, pandas, and numpy. It downloads historical prices for multiple assets and calculates daily returns, cumulative returns, volatility, moving averages, and best/worst trading days. The goal was to practice time-series analysis and core financial metrics used in market analysis.”
